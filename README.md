# Slime Arcade 🟢🏐⚽

A fast-paced, tactile, physics-based cartoon arcade game featuring squishy soft-body slimes! Compete in 1v1 **Volleyball** and **Soccer** matches against an intelligent AI bot or play with a friend in **2-Player Local Mode**.

---

## 🎮 Game Features

- **Soft-Body Jelly Physics:** Slimes squish, stretch, wobble, and blink dynamically as they jump, land, dive, and hit the ball.
- **Dual Game Modes:**
  - 🏐 **Volleyball Mode:** Rally the ball across the center net and score by bouncing it on your opponent's court (First to 7 wins!).
  - ⚽ **Soccer Mode:** Dribble, volley, and score into the opponent's goal net!
- **Super Power Moves:**
  - Build up your **Super Meter** with rallies and spikes.
  - Unleash explosive elemental super spikes, warp dashes, and shockwaves!
- **8 Unique Slime Characters:**
  - 🟢 **Goopy Green** (Acid Spike)
  - 🩷 **Bubblegum** (Bubble Shield)
  - 🔥 **Magma Blaze** (Meteor Smash)
  - ⚡ **Neon Cyan** (Warp Dash)
  - 👑 **Golden King** (Royal Shockwave)
  - 🌌 **Cosmic Void** (Gravity Warp)
  - ❄️ **Mint Frost** (Ice Frost)
  - 🧪 **Toxic Sludge** (Sludge Bomb)
- **Smart AI Bot:** 3 difficulty levels (*Casual Jelly*, *Slime Pro*, and *Jiggle Master*).
- **Tactile 3D Cartoon UI:** Pill buttons, glossy bevels, responsive screen warping (`100dvh`), and custom synthesized Web Audio sound effects.
- **Mobile Touch Controls:** On-screen virtual buttons for mobile and tablet play.

---

## 🕹️ Controls

| Action | Player 1 (Solo / 1P) | Player 2 (Local 2P) | Mobile / Touch |
| :--- | :--- | :--- | :--- |
| **Move Left / Right** | `A` / `D` or `←` / `→` | `←` / `→` | ◀ / ▶ Touch Buttons |
| **Jump** | `W` or `↑` | `↑` | ▲ Touch Button |
| **Super Power Spike** | `Space` | `Enter` | ⚡ Spike Button |
| **Pause** | `P` | `P` | ⏸ Pause Button |
| **Restart** | `R` | `R` | 🔄 Restart Button |
| **Mute Sound** | `M` | `M` | 🔊 Sound Button |
